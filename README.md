# 🚀 Titanic Dataset Preprocessing Pipeline

## 📖 Project Description

This project builds a complete **data preprocessing pipeline** for the Titanic dataset. It focuses on transforming raw, inconsistent data into a clean and structured format ready for machine learning tasks.

---

## 🔍 What This Project Covers

* Data inspection and missing value analysis
* Smart imputation techniques (median & mode)
* Feature encoding for categorical variables
* Outlier detection and removal using IQR
* Feature scaling using standardization

---

## 🧹 Data Cleaning Highlights

* Missing values in **Age** and **Embarked** handled efficiently
* **Cabin** column removed due to high null percentage
* Categorical data converted into numerical form
* Outliers in **Fare** reduced to improve data consistency

---

## 📈 Result

A refined dataset with:

* No missing values
* Reduced noise and outliers
* Scaled numerical features
